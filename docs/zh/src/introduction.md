# 引言

> 🌐 [English](../../en/book/index.html) · **中文**

**Dr Strange** 是一个用 Rust 编写的 AI 原生嵌入式图数据库。

它是一个从设计之初即面向 AI 工作负载的图数据库：嵌入（embedding）是一等值类型，
相似度检索与图遍历并行工作，引擎向智能体（agent）暴露相应的原语——自然语言查询、
实时变更流、时间旅行——而非在传统图数据库之上事后添加 AI 功能。

与 SQLite 一样，它是**嵌入式**的：一个链接进应用的库，背后是单个磁盘上的数据库，
无需运维任何服务。而与 SQLite 不同的是，它也可以**对外提供服务**：`drsg serve`
暴露一个 JSON-RPC 2.0 接口、一个浏览器仪表盘，以及一个 WebSocket 变更流，并配有
六种语言的客户端 SDK。

## 目标读者

- **应用开发者**：构建知识图谱、GraphRAG 流水线或智能体的长期记忆，需要在单一系统
  中同时具备图与向量存储。
- **AI 与智能体工程师**：期望数据库承担更多工作——将问题编译为查询、在变更提交时
  推送、并按需重建历史状态。
- **读者**：对 AI 原生存储引擎的构造感兴趣者。

## 本书结构

前几章确立基础要点：Dr Strange 是什么、如何构建，以及其"AI 原生"设计意味着什么。
中间几章是查询语言以及各访问面的参考：Web 界面、各语言 SDK、命令行，以及面向
LLM 智能体的 MCP 服务。最后一章阐述其架构。
