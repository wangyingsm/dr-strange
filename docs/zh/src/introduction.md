# 引言

> 🌐 [English](../../en/book/index.html) · **中文**

**Dr Strange** 是一个用 Rust 编写的 AI 原生嵌入式图数据库。

它是一个从第一天起就为 AI 工作负载而设计的图数据库——嵌入（embedding）是一等
值类型，相似度检索与图遍历比肩而立，引擎会用智能体（agent）的语言与你对话（自然
语言查询、实时变更流、时间旅行），而不是在一个传统图数据库上事后拼装 AI 功能。

与 SQLite 一样，它是**嵌入式**的：一个链接进你程序的库，一个磁盘上的数据库文件，
无需运维任何服务。而与 SQLite 不同的是，它也可以**对外提供服务**：`drsg serve`
会启动一个 JSON-RPC 2.0 接口、一个浏览器仪表盘，以及一个 WebSocket 变更流，并配有
五种语言的客户端 SDK。

## 本书面向谁

- **应用开发者**：想把图与向量放在同一个地方，来构建知识图谱、GraphRAG 流水线，
  或智能体的长期记忆。
- **AI / 智能体工程师**：希望数据库承担更多工作——把问题变成查询、变更发生时主动
  推送、并能回答"上周二这里长什么样"。
- **好奇的你**：想看看一个 AI 原生存储引擎是如何搭建起来的。

## 本书结构

前几章帮你快速上手——Dr Strange 是什么、如何安装、以及它的"AI 原生"体现在哪里。
中间几章是查询语言以及各种访问方式的参考：Web 界面、各语言 SDK、命令行，以及面向
LLM 智能体的 MCP 服务。最后一章掀开引擎的盖子，讲解其架构。
