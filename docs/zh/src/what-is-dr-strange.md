# 什么是 Dr Strange？

Dr Strange 是一个用 Rust 编写的 **AI 原生嵌入式图数据库**。这句话包含三项主张，
下文逐一说明：它存储的是**图**，它是**嵌入式**的，它是 **AI 原生**的——从设计之初
即面向 AI 工作负载，而非事后加装。

## 数据模型：以"平面"组织的属性图

Dr Strange 存储的是一张**属性图（property graph）**：

- **节点（Node）** 是实体——一个人、一篇文档、一件商品。每个节点都有一组
  **标签（label）**（即它的类型，如 `Person`、`Doc`），以及一个自由形式的
  **属性（property）** 映射。
- **边（Edge）** 是节点之间有向、带类型的关系——`(alice) -[:KNOWS]-> (bob)`。
  边同样可以携带属性。
- **属性** 是带类型的值：字符串、数字、布尔、字节块、列表、嵌套映射——以及至关
  重要的**向量（vector，即嵌入）**，它是一等值类型，而非事后补丁。

除了引擎内部的数字 id，节点还可以携带一个由调用方提供的 **外部键（external key）**
（一个稳定、对人友好、在其所属平面内唯一的标识）。

数据被组织进一个个 **平面（plane）**——存在于同一个数据库文件中、相互独立的具名
图命名空间。平面就像 schema 或 namespace：你可以为每个项目、每个租户或每次实验各用
一个平面。id 在整个数据库范围内全局唯一，但**每一次查询都在某一个平面的上下文中
执行**，因此各平面彼此干净地隔离。一个全新的数据库总是包含一个 `startup` 平面。

## "AI 原生"的主张

多数增加了 AI 能力的数据库，是在传统引擎上附加一列向量，再外呼一个模型服务。
Dr Strange 反转了这一结构：AI 应用所需的能力，本身即为引擎的核心特性：

- **嵌入是一等公民。** 向量和其它属性值一样，用 HNSW 原生建立索引，因此相似度
  检索既快，又活在查询引擎**内部**。
- **检索融合多路信号。** 向量相似度、BM25 关键词相关性、图上邻近度融合为一个统一
  的排序结果——这正是 GraphRAG 的核心。
- **引擎与智能体对话。** 用自然语言提问，拿回一个查询计划，执行它，得到一张连通的
  子图；订阅一个平面，在变更提交时实时收到它；读取图在任意历史时刻的样子。

### 一个具体例子：GraphRAG

假设你已经把一批文档作为图导入——`Doc` 节点带有 `embedding` 属性，通过 `CITES`、
`MENTIONS` 边连到 `Concept` 节点。一次 GraphRAG 查找就是一条查询：

```text
SEARCH (d:Doc) ON embedding NEAR "how does time-travel work" TOPK 5 RETURN d
```

它将问题嵌入为向量，检索出最相似的五篇文档；由于结果本身即为图节点，遍历可直接从其
继续——进入它们提及的概念，以及引用它们的文档——组装出纯向量库单凭自身无法企及的、
扎实的上下文。

## Dr Strange 的定位

- **像 SQLite** 一样，它是嵌入式的：一个库加一个磁盘上的数据库，无需运行任何服务。
  当你需要仪表盘、HTTP/WebSocket 接口和多客户端访问时，也可以启动一个服务
  （`drsg serve`）。
- **不同于传统图数据库**（如 Neo4j），向量与混合检索内建于核心，且整套接口是围绕
  智能体设计的——自然语言、变更流、时间旅行。
- **不同于纯向量数据库**，它的存储单位是一张*图*：你得到的是关系、遍历与图算法，
  而不仅仅是最近邻。

对于围绕知识图谱、GraphRAG 流水线或智能体长期记忆构建的应用，Dr Strange 意在作为
容纳这一切的单一存储。

## 特性一览

| 能力 | 它带给你什么 |
|---|---|
| **平面（Planes）** | 一个数据库中容纳多张相互独立的图 |
| **一等嵌入** | 向量属性，原生 HNSW 索引 |
| **混合检索** | 向量 + 关键词（BM25）+ 图邻近度的融合检索 |
| **查询语言** | 可序列化的逻辑计划，以及一套 openCypher 子集 |
| **图算法** | PageRank、连通分量、最短路径、Louvain |
| **自然语言查询** | 用自然语言提问 → 生成计划 → 执行 |
| **时间旅行** | 读取图在某个历史提交或时间戳时的样子 |
| **变更流** | 订阅一个平面，实时接收其变更 |
| **备份 / 恢复** | 一致、保 id 的整库快照 |
| **访问方式** | Web 界面、五种语言 SDK、命令行，以及 MCP 服务 |

## v1.0 意味着什么

v1.0 是一个完整的、嵌入式的、AI 原生的图数据库，具备上述全部能力、一个存储引擎
（一个手写的 LSM，另有一个遗留可选项），以及一套稳定的、SDK 由其生成的 JSON-RPC
线协议。接下来的各章将带你使用它的每一个部分。
