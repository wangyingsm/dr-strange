# Web 界面

`drsg serve` 附带一个单页仪表盘（已嵌入二进制），供你在浏览器中浏览与操作数据库。
它使用与各 SDK 相同的 JSON-RPC 接口，另加一条用于实时更新的 WebSocket。

## 三个视图

- **仪表盘（Dashboard）** —— 一眼看清健康状况（平面、节点、边、标签、边类型、
  索引、平均度、提交数、磁盘占用，全部实时），并提供平面卡片以创建、导出、删除
  平面。
- **浏览（Explore）** —— 一块交互式图画布，由一排选项卡工具栏驱动：
  **Filters**（按标签播种）、**GraphQL/Run**（Cypher 输入框，带关键词提示）、
  **Algorithms**（叠加 PageRank / 连通分量 / 最短路径 / Louvain）、
  **Hybrid**（融合检索）、**Ask**（自然语言查询）、
  **Time-travel**（用滑块查看图在某个历史提交时的样子），以及
  **Live**（变更落库时实时流式呈现）。
- **AIgest** —— 上传或粘贴一篇文档，借助 LLM 将其转化为图结构，并在写入前预览
  实体与关系。

## 顶部搜索

一个对当前平面的快速搜索框（子串或语义），它同样遵从时间旅行游标——可以搜索图在
某个历史提交时*当时*的样子。

## 小节（草拟）

- 启动界面并鉴权（令牌 vs. 同源本地界面）
- 仪表盘：统计盒子与平面卡片
- 浏览：画布、选中/检视，以及各个工具栏选项卡
- 搜索：快速 vs. 语义，以及搜索历史快照
- 界面中的时间旅行：滑块与"as of"指示
- Live 变更流：观察变更并跳转到节点
- AIgest：从头到尾的导入流程
- 关于设计的说明（随主题明暗、内嵌、零外部调用）
