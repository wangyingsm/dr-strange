# Web 界面

`drsg serve` 提供一个内嵌于二进制的单页仪表盘，供你在浏览器中检视与操作数据库。它
通过 HTTP 使用与各 SDK 相同的 JSON-RPC 接口，并通过一条 WebSocket 获取实时更新。由于
是内嵌的，它不发起任何外部网络请求：所有资源均由同一来源（origin）提供，所有渲染
都在本地完成。

## 访问与鉴权

打开 `drsg serve` 报告的地址（默认 `http://127.0.0.1:7700`）。当配置了令牌时，服务端
会将其注入所提供的页面，于是同源界面自动完成鉴权；当未配置令牌时，同源来源检查即
授权本地界面。无论如何，跨源请求都会被拒绝。

界面包含三个视图，从顶部选择：**Dashboard**、**Explore** 与 **AIgest**。

## Dashboard（仪表盘）

Dashboard 呈现数据库的健康状况与平面管理。

- **健康状况。** 一组统计——平面、节点、边、标签、边类型、已声明索引、平均度、
  提交数（提交序号）与磁盘占用。它们通过 WebSocket 实时推送，因而随数据库变化而更新；
  一个连接指示器显示实时/离线状态。
- **平面卡片。** 每个平面一张卡片，显示其名称、描述与节点/边计数。卡片可选定该平面
  （作为全局上下文）、将其导出为 JSONL（一个可被命令行 `import` 读回的下载），或在
  一个键入确认的对话框后删除它。一张"新建平面"卡片用于创建平面。

## Explore（浏览）

Explore 是一块由选项卡工具栏驱动的交互式图画布。选中一个节点或边会打开一个检视器，
显示其标签/类型与属性（向量被折叠在一个控件之后，而非直接打印）；双击一个节点会
扩展其邻域；从一个节点拖拽到另一个节点会打开新建边对话框，并预填两个端点。

### 阅读一张稠密的图

任何规模的平面都超出一块画布一次所能呈现的范围，因此 Explore 先画出**骨架**，其余
的部分由你来索取。

- **按重要性取种子。** 初始视图是连接最多的 40 个节点及它们之间的边，而不是扫描最先
  遇到的 40 个——是一个可读的形状，而非一份任意的样本。**Show more（显示更多）**
  会将其扩展到 100、200、500。排序依据是度数；`graph.seed` 也提供 PageRank，但
  PageRank 会把权重汇聚到汇点上，以至于一个中心节点的得分可能低于它自己的邻居。
- **图例即过滤器。** 点击一个标签即可隐藏该类别，再次点击则恢复。是隐藏而非淡出：
  你所关闭的类别，就不属于当前的问题。
- **拥挤的中心节点会被折叠。** 当某个节点拥有超过二十个**叶节点**——即只与它相连、
  别无他连的邻居——它们会折叠为一个标注着数量的圆点。点击该圆点即可展开。没有任何
  内容被丢弃，且你已选中的叶节点绝不会被折叠。
- **扇形会被分组。** 在该阈值以下，一个中心节点的叶节点会按标签成弧段排布在其四周，
  于是环形读起来是若干区域，而非一片模糊。
- **重要性会撑开布局。** 与连接紧密的节点相接的边会被排布得更长，好让繁忙的邻域有
  余地被看清。
- **选中即聚焦。** 选中项及其直接邻居保持全强度，再外一圈变暗，更远处则隐去并舍弃
  标签。选中一条**边**会同时聚焦它的两个端点——一条边是关于两个事物的陈述。

节点大小反映其连接的紧密程度（并计入折叠在它之下的部分），图例则将颜色映射到标签。

工具栏选项卡：

- **Filters / Operations** —— 从某个标签（或整个平面）为画布播种。
- **GraphQL / Run** —— 一个用于 Cypher 子集的查询框（见[第 4 章](./query-language.md)）；
  一个关键词幽灵提示会在你键入时补全子句关键词，按 Tab 接受。读操作绘制其结果；写
  操作执行改动并重新加载。
- **Algorithms** —— 运行 PageRank、连通分量、最短路径或 Louvain，并将结果叠加到当前
  图上（得分体现为节点大小/颜色，分量/社区体现为颜色分组）。
- **Hybrid** —— 融合的向量 + 关键词 + 图邻近度检索，其各路信号与标签在栏中选择。
- **Ask** —— 一个自然语言问题；生成的计划会被展示（带一个复制控件），其连通结果被
  绘制出来。
- **Time-travel** —— 一个覆盖提交历史的滑块（见下文）。
- **Live** —— 变更流（见下文）。

## 搜索

顶部带有一个针对当前平面的快速搜索，有两种模式：

- **文本** —— 在键、标签与字符串属性上进行子串匹配。
- **语义** —— 按嵌入相似度排序（带一个嵌入提供方选择器）。

选中一个结果会在 Explore 中聚焦到该节点或边。搜索同样遵从时间旅行游标：在钉住某个
历史提交后，它搜索图在该提交时*当时*的样子。

## 时间旅行

在原生后端的服务上，Explore 的 **Time-travel** 选项卡会探测可查询窗口
（`plane.history`），并在其可用时呈现一个覆盖提交序号的滑块，其最新端带有一个
**Live** 控件。向后拖动会将图重绘为该提交时的样子；播种与节点扩展读取历史快照。画布上
的一个标记在所有选项卡上都指示所钉住的提交，并在被关闭时将视图恢复为实时。顶部搜索
反映同一个游标。在非原生后端上，该选项卡不出现。

## Live 变更流

Explore 的 **Live** 选项卡通过 WebSocket 打开一个 `plane.watch` 订阅，并在提交落库时
将其流式呈现，最新者在前：每一条显示操作（创建 / 更新 / 删除，以颜色区分）、种类
（节点 / 边）、键或 id、标签，以及提交序号。该流可以暂停与恢复，并可收窄到单个标签；
选中一个节点变更会在画布中聚焦到它。

## AIgest

AIgest 视图将一篇文档导入当前平面（见[第 3 章](./ai-native.md)）。上传或粘贴文本——
Markdown 与纯文本，或 Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV 与 PDF
（它们会被转换为 Markdown，使模型看到的是标题、表格与列表，而非散乱的字符）——选择
对话与嵌入提供方，然后 **Preview（预览）**：模型
抽取实体与关系并提出方案。**Write to graph（写入图）** 会提交所预览的方案，不再产生
任何额外的模型调用。可选项包括链接到既有节点（以避免重复）与跳过嵌入生成。

上传控件旁还有一行 **URL**：粘贴一个地址，可选地再填一个主题，然后 **Fetch（抓取）**。
返回的并不是直接填进文本框的正文，而是一份*列表*——该页面及其所指向的页面，各自带有
相关性得分、标题与大小，越过阈值者默认勾选。取消勾选某一项即可将其从文档中移除，且
不会产生任何新的请求；一个可展开的折叠区则列出未被保留者及其原因。在这份列表看起来
无误之前，不会有任何内容变成 token（[第 3 章](./ai-native.md#从-url-读取)）。

**Mode（模式）** 决定抽取结果被清理到何种程度——`coarse`、`fine`（默认）或 `super`
——并与提供方的选择一样被记住，因为它是一项长期偏好而非每次运行的临时决定。选择
`super` 会在该控件正下方给出提示：它会将每个实体与其全部段落一并重读，输入 token
用量约为 15 倍。各模式各自换取什么，见[第 3 章](./ai-native.md#抽取精度)。

## 设计

仪表盘随主题明暗（跟随观看者的浅色/深色偏好），且完全自包含：由于它是内嵌且同源的，
它不依赖任何外部 CDN、字体或服务，也不发起任何超出所属服务之 API 与 WebSocket 的
请求。
