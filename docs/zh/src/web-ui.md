# Web 界面

`drsg serve` 提供一个内嵌于二进制的单页仪表盘，供你在浏览器中检视与操作数据库。它
通过 HTTP 使用与各 SDK 相同的 JSON-RPC 接口，并通过一条 WebSocket 获取实时更新。由于
是内嵌的，它不发起任何外部网络请求：所有资源均由同一来源（origin）提供，所有渲染
都在本地完成。

## 访问与鉴权

打开 `drsg serve` 报告的地址（默认 `http://127.0.0.1:7700`）。当配置了令牌时，服务端
会将其注入所提供的页面，于是同源界面自动完成鉴权；当未配置令牌时，同源来源检查即
授权本地界面。无论如何，跨源请求都会被拒绝。

界面包含三个视图，从顶部选择：**Dashboard**、**Explore** 与 **AIgest**。

## Dashboard（仪表盘）

Dashboard 呈现数据库的健康状况与平面管理。

- **健康状况。** 这里展示一组统计数据：平面、节点、边、标签、边类型、已声明索引、
  平均度、提交数（提交序号）与磁盘占用。它们通过 WebSocket 实时推送，会随数据库变化
  而更新，一个连接指示器显示实时/离线状态。
- **平面卡片。** 每个平面一张卡片，显示其名称、描述与节点/边计数。卡片可选定该平面
  （作为全局上下文）、将其导出为 JSONL（一个可被命令行 `import` 读回的下载），或在
  一个键入确认的对话框后删除它。一张"新建平面"卡片用于创建平面。

## Explore（浏览）

Explore 是一块由选项卡工具栏驱动的交互式图画布。选中一个节点或边会打开一个检视器，
显示其标签/类型与属性（向量被折叠在一个控件之后，而非直接打印）；双击一个节点会
扩展其邻域；从一个节点拖拽到另一个节点会打开新建边对话框，并预填两个端点。

### 阅读一张稠密的图

任何规模的平面都超出一块画布一次所能呈现的范围，因此 Explore 先画出**骨架**，其余
的部分由你来索取。

- **按重要性取种子。** 初始视图取的是连接最多的 40 个节点及它们之间的边，而不是
  扫描到的最先 40 个，为的是给出一个可读的形状，而非一份任意的样本。**Show
  more（显示更多）** 会将其扩展到 100、200、500。排序依据是度数；`graph.seed`
  也提供 PageRank，但 PageRank 会把权重汇聚到汇点上，以至于一个中心节点的得分
  可能低于它自己的邻居。
- **图例即过滤器。** 点击一个标签即可隐藏该类别，再次点击则恢复。这里做的是隐藏
  而不是淡出：你关掉的类别，就不再属于当前要看的问题。
- **拥挤的中心节点会被折叠。** 某个节点的**叶节点**（只与它相连、别无他连的邻居）
  一旦超过二十个，就会折叠成一个标注数量的圆点，点击即可展开。没有任何内容被
  丢弃，你已经选中的叶节点也绝不会被折叠。
- **扇形会被分组。** 在该阈值以下，一个中心节点的叶节点会按标签成弧段排布在其四周，
  于是环形读起来是若干区域，而非一片模糊。
- **重要性会撑开布局。** 与连接紧密的节点相接的边会被排布得更长，好让繁忙的邻域有
  余地被看清。
- **选中即聚焦。** 选中项及其直接邻居保持全强度，再外一圈变暗，更远处则隐去并舍弃
  标签。选中一条**边**会同时聚焦它的两个端点，因为一条边本身就是关于两个事物的
  陈述。

节点大小反映其连接的紧密程度（并计入折叠在它之下的部分），图例则将颜色映射到标签。

工具栏选项卡：

- **Filters / Operations** —— 从某个标签（或整个平面）为画布播种。
- **Cypher / Plot** —— 一个把匹配结果*绘制*出来的查询框，用于以查询（而非标签）为
  画布播种（见[第 4 章](./query-language.md)）；一个关键词幽灵提示会在你键入时补全
  子句关键词，按 Tab 接受。写操作执行改动并重新加载。若想把查询结果当作数据来读，
  请用下面的 **Query** 视图。
- **Algorithms** —— 运行 PageRank、连通分量、最短路径或 Louvain，并将结果叠加到当前
  图上（得分体现为节点大小/颜色，分量/社区体现为颜色分组）。
- **Hybrid** —— 融合的向量 + 关键词 + 图邻近度检索，其各路信号与标签在栏中选择。
- **Ask** —— 一个自然语言问题；生成的计划会被展示（带一个复制控件），其连通结果被
  绘制出来。
- **Time-travel** —— 一个覆盖提交历史的滑块（见下文）。
- **Live** —— 变更流（见下文）。

## Query（查询）

与 Dashboard、Explore 并列的独立视图：用来向平面提问并阅读答案——而 Explore 里的
那个查询框，问同样的问题是为了把它画出来。

编辑器是多行的，因为值得占一个页面的查询很少只有一行：**⌘/Ctrl + Enter** 运行，
回车即换行，Tab 接受与 Explore 相同的关键词补全（两个框共用同一份关键词表，因此
不会各自漂移）。编辑器下方给出若干示例查询作为起点，输入的文本也会在刷新后保留。

结果呈现为查询所要的形状：

- **投影**（`RETURN n.file, count(*) AS n`）以表格返回，并给出行数、列数与耗时，
  还有一个**复制**控件，把整张表以制表符分隔的文本放进剪贴板——含表头，可直接粘进
  电子表格；
- 返回**完整记录**的查询（`RETURN n`）按键、标签以及放得下的属性逐条列出，并写明：
  绘图是 Explore 的职责；
- **写操作**报告其变更计数。

无法编译的查询会显示解析器自己的消息——它指名的是语法构造，而不是一个字符位置。

## 搜索

顶部带有一个针对当前平面的快速搜索，有两种模式：

- **文本** —— 在键、标签与字符串属性上进行子串匹配。
- **语义** —— 按嵌入相似度排序（带一个嵌入提供方选择器）。

选中一个结果会在 Explore 中聚焦到该节点或边。搜索同样遵从时间旅行游标：在钉住某个
历史提交后，它搜索图在该提交时*当时*的样子。

## 时间旅行

在原生后端的服务上，Explore 的 **Time-travel** 选项卡会探测可查询窗口
（`plane.history`），并在其可用时呈现一个覆盖提交序号的滑块，其最新端带有一个
**Live** 控件。向后拖动会将图重绘为该提交时的样子；播种与节点扩展读取历史快照。画布上
的一个标记在所有选项卡上都指示所钉住的提交，关闭后视图会恢复为实时。顶部搜索反映
同一个游标。在非原生后端上，该选项卡不出现。

## Live 变更流

Explore 的 **Live** 选项卡通过 WebSocket 打开一个 `plane.watch` 订阅，并在提交落库时
将其流式呈现，最新者在前：每一条显示操作（创建 / 更新 / 删除，以颜色区分）、种类
（节点 / 边）、键或 id、标签，以及提交序号。该流可以暂停与恢复，并可收窄到单个标签；
选中一个节点变更会在画布中聚焦到它。

## AIgest

AIgest 视图把一篇文档导入当前平面（见[第 3 章](./ai-native.md)）：先上传或粘贴
文本——支持 Markdown、纯文本，以及 Word、PowerPoint、Excel、OpenDocument、RTF、
EPUB、CSV 与 PDF（这些格式会先转换为 Markdown，让模型看到的是标题、表格与列表，
而不是一堆散乱的字符）；再选择对话与嵌入提供方；最后点 **Preview（预览）**，模型
就会抽取实体与关系并给出方案。**Write to graph（写入图）** 会提交预览好的方案，
不会再产生任何额外的模型调用。可选项包括链接到既有节点（避免重复）与跳过嵌入
生成。

上传控件旁还有一行 **URL**：粘贴一个地址，可以再填一个主题，然后点
**Fetch（抓取）**。返回的不是直接填进文本框的正文，而是一份*列表*：该页面及它
链接到的页面，各自带着相关性得分、标题与大小，超过阈值的默认勾选。取消勾选某
一项，就能把它从文档中移除，且不会产生任何新的请求；一个可展开的折叠区会列出
未被保留的页面及其原因。在这份列表看起来没问题之前，不会有任何内容变成 token
（[第 3 章](./ai-native.md#从-url-读取)）。

**Mode（模式）** 决定抽取结果被清理到什么程度：`coarse`、`fine`（默认）或
`super`，这个选择会和提供方一起被记住，因为它是一项长期偏好，而不是每次运行都要
重新决定的临时选项。选中 `super` 时，控件正下方会给出提示：它会把每个实体连同
它的全部段落一并重读，输入 token 用量约为 15 倍。各模式各自换来什么，见
[第 3 章](./ai-native.md#抽取精度)。

## 设计

仪表盘会跟随主题明暗（即观看者的浅色/深色偏好），并且完全自包含：因为它是内嵌
且同源的，不依赖任何外部 CDN、字体或服务，除了所属服务自己的 API 与 WebSocket
之外，也不会发起任何其它请求。
