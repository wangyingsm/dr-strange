# AI 原生

本章介绍那些让 Dr Strange 成为一个*为* AI 而生、而非仅仅*带有* AI 特性的数据库的
能力。

## 嵌入作为一等值

一个取值为向量的属性，就是一个嵌入。在某个 `(标签, 属性)` 对上声明索引，引擎便会
为它维护一个 HNSW 索引，于是相似度检索又快、又紧挨着图本身：

```text
SEARCH (d:Doc) ON embedding NEAR "how does time-travel work" TOPK 5 RETURN d
```

文本会在服务端被嵌入（提供方密钥来自服务端环境），返回最相近的五篇文档——之后你就能
像对待任何其它结果一样，从它们出发继续遍历。

## 混合检索

真实的检索很少只想要单一信号。Dr Strange 把三路信号融合成一个排序列表：

- **向量** —— 嵌入相似度；
- **关键词** —— 基于词干化、按语言处理的文本索引之上的 BM25；
- **图** —— 到最强命中点的邻近度，随跳数逐跳衰减。

## 自然语言查询

用自然语言提问；引擎会以该平面的 schema 为依据，让语言模型产出一个查询计划（带有
有界的修复循环，以及基于嵌入的工具，用来找到正确的边与实体），执行它，并返回连通的
子图。

## 导入文档（AIgest）

把非结构化文本（Markdown、PDF、DOCX）转化为图结构：由 LLM 抽取实体与关系、生成
嵌入、与既有数据建立链接，并写入结果——这正是仪表盘 **AIgest** 页背后的流水线。

## 小节（草拟）

- 向量属性与声明 HNSW 索引
- 关键词（BM25）索引：词干化、语言、停用词
- 混合检索及其各路信号的融合方式
- `plane.ask`：自然语言 → 查询计划 → 执行（智能体循环、修复、工具）
- AIgest：文档 → 实体/关系 → 嵌入 → 链接 → 写入
- 提供方与密钥（OpenAI / DeepSeek / Qwen / Ollama），均在服务端
- 时间旅行与变更流，作为智能体的原语（交叉引用）
