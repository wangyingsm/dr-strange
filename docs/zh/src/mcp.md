# MCP

`drsg-mcp` 是一个 [Model Context Protocol](https://modelcontextprotocol.io)
服务，它内嵌 Dr Strange，将数据库作为一组工具暴露给 LLM 智能体。一个智能体（在兼容
的客户端中）便可以直接检索、查询、遍历、运行算法、用自然语言提问、导入文档——无需你
编写任何胶水代码。

## 为什么是 MCP

MCP 本身就是 JSON-RPC 2.0，与 Web 后端所讲的是同一套协议，因此 MCP 服务是一个自然
的、一等的接口，而非事后附加。它通过 stdio 运行并内嵌核心引擎，于是智能体便拥有了
一个真正的图 + 向量存储，作为其原生工具。
